# P1.1 — expired lease reclaim + crash probe

**Date:** 2026-10-23

## 1. Real expired lease reclaim — PASS

Created card DSH-27, set it to `in_progress`, then created a real 1-second
lease through `LeaseStore` and waited 2 seconds.

The supervisor started after expiry, reclaimed the card, prompted the worker,
and wrote Done:

```text
DSH-27  done
blockedReason: null
version: 4
comment author: builder
evidence: lease reclaimed
```

This exercised the real `in_progress` + expired-lease path, not only a unit
test.

## 2. Crash probe — plugin-level PASS, OS-level NOT DONE

Created card DSH-28 with a long-running worker prompt. Once it was
`in_progress`, the Kanban plugin was disabled and instantly re-enabled
(plugin-level hard stop/reload).

Observed:

```text
status: in_progress
lease: active, 360s
comments: 0
duplicate prompt: none
```

The lease prevented a second prompt. The card was archived after the probe.

### Honest limitation

This is not an OS `SIGKILL` of the DSH app. Killing the app would terminate this
GUI session. A true process-crash test needs a detached restart harness or a
second headless host. The persisted lease/session behavior is the same code
path, but the test boundary is the plugin lifecycle, not the OS process.
