# M1.5b：Relay 默认接入 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans`.

**Goal:** 让普通用户不需要 GitHub、不需要公网端口、不需要 tunnel，就能把一个 bot 接到 DSH Kanban。Relay 成为默认 transport；GitHub 只保留为 fallback/debug。

**Architecture:** 自托管最小 relay，HTTP long-poll，信封透明转发。DSH 主动连 relay；bot 也主动连 relay；双方都不暴露入站端口。Relay 只存短期消息和 channel，不存任务状态。

**Tech Stack:** Python 3.9+ stdlib；`http.server`/`urllib`；现有 `bridge/envelope.py`；无新依赖。

**Spec:** `docs/superpowers/plans/2026-10-22-m1.5-grokbot-bridge.md` M1.5a；本文件是 M1.5b。

## Global Constraints

- 不要求用户有 GitHub。
- 不要求 DSH 有公网入站端口。
- Relay 不是 source of truth；Kanban 是。
- 一个 channel = 一个 bot 接入。
- 消息只转发，不执行。
- Token 只来自本地/环境；不提交。
- 先 HTTP long-poll；WebSocket 后置。
- GitHub adapter 继续存在，但不是默认。

## 用户流程

```text
  ↓

```

没有 GitHub issue。

## Relay API

```text
POST /v1/channels
  Authorization: Bearer <relay-admin-token>
  -> { channel, token, url }

POST /v1/channels/{channel}/messages
  Authorization: Bearer <channel-token>
  body: envelope
  -> { seq }

GET /v1/channels/{channel}/messages?after=<seq>&wait=25
  Authorization: Bearer <channel-token>
  -> { messages: [{seq, envelope}], next }
```

- Channel id: random 128-bit.
- Token: random 256-bit.
- Messages in memory + optional JSON persistence; TTL 24h.
- Long-poll max 25s; client reconnects.
- No message larger than 64 KB.
- Relay logs metadata only; no envelope bodies.

## Task 1: Transport interface

```python
class Transport:
    def open(self, request: dict) -> str: ...
    def replies(self, ref: str, after: str | None = None) -> tuple[list[dict], str | None]: ...
    def close(self, ref: str) -> None: ...
```

- `GitHubTransport` implements it with issue number as `ref`, comment id as cursor.
- `RelayTransport` implements it with channel as `ref`, seq as cursor.
- Orchestrator only sees `Transport`.

Tests: fake transport; orchestrator creates/opens/reads/closes without GitHub imports.
