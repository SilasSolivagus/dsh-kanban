# P1.2 Review Gate (门神) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** No builder result reaches Done until a separate reviewer worker has inspected the card and its evidence.

**Architecture:** Add a `reviewing` status that lives in Running, a `reviewer` worker role, and a second supervisor pass. The builder hands Done candidates to `reviewing`; the reviewer claims the card with a lease, reads the builder evidence, and either passes it to Done or rejects it into Needs you. `in_review` remains the human “等你确认” state and is not reused.

**Tech Stack:** Node 22, ESM, `node:test`, Cordis Host/Client bundles, existing `KanbanStore`, `LeaseStore`, `DshWorkerSession`.

**Spec:** `docs/superpowers/plans/2026-10-23-agent-board-product.md` (P1 exit: evidence before Done; reviewer gate), `docs/ux-review-2026-10-23.md` (evidence is not first-class today)

## Global Constraints

- One supervisor process only.
- One worker per role in P1.2 (`builder` and `reviewer`).
- Never write Done without a reviewer pass when a reviewer is configured.
- Reviewer actor must differ from the builder actor.
- Every write keeps the existing `version` check; stale writes must surface `TASK_VERSION_CONFLICT`.
- Lease is claimed before any prompt and released on every terminal path.
- `in_review` remains the human review state; do not change its label or `attentionReason`.
- Do not add a hosted server, A2A, Grok adapter, or model-tier routing in this plan.
- Keep the existing 256 tests green; add review tests before implementation.

async listReviewQueue(actorId) {
  const archivedProjects = new Set(
    this.#store.bootstrap().projects.filter((p) => p.archivedAt).map((p) => p.id),
  )
  return this.#store.bootstrap().tasks.filter((task) =>
    task.status === 'reviewing' &&
    !task.archivedAt &&
    !archivedProjects.has(task.projectId),
  )
}

async claimReview(id, actor, leaseSeconds) {
  const task = this.getTask(id)
  await this.#leases.claim(id, actor, leaseSeconds)
  return task
}

async submitForReview(id, version, actor) {
  return this.#store.updateTask(id, { version, status: 'reviewing' }, actor)
}

- [ ] **Step 3: Implement the review pass**

```js
async #runReviewer(reviewer) {
  const actor = actorFor(reviewer)
  const queue = await this.#board.listReviewQueue(reviewer.id)
  for (const task of queue) {
    if (isTerminalStatus(task.status)) continue
    if (task.assignee?.id === reviewer.id) {
      await this.#board.block(task.id, task.version, 'Reviewer cannot review their own work', actor)
      continue
    }
    const claimed = await this.#board.claimReview(task.id, actor, leaseSecondsFor(reviewer))
    try {
      await this.#sessions.ensure(reviewer)
      const rolePrompt = await this.#readRolePrompt(reviewer)
      const builderEvidence = await this.#builderEvidence(task.id)
      const prompt = buildReviewPrompt({ worker: reviewer, task: claimed, rolePrompt, builderEvidence })
      const response = await this.#sessions.prompt(reviewer, prompt, { timeoutMs: timeoutMsFor(reviewer) })
      const result = parseReviewResult(response.text)
      if (result.verdict === 'pass') {
        await this.#board.comment(task.id, renderReviewComment(result), actor)
        await this.#board.updateStatus(task.id, claimed.version, 'done', actor)
      } else {
        await this.#board.comment(task.id, renderReviewComment(result), actor)
        await this.#board.block(task.id, claimed.version, result.summary, actor)
      }
    } catch (error) {
      await this.#board.block(task.id, claimed.version, reasonFor(error), actor)
    } finally {
      await this.#release(task.id, actor)
    }
  }
}
```

for (const worker of this.#workers.filter((w) => w.role === 'builder')) {

for (const worker of this.#workers.filter((w) => w.role === 'reviewer')) {
